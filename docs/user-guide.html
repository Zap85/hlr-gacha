使用说明

快速开始

  1. 选择当前日期和目标卡池 / 目标日期。建议优先使用“目标卡池”模式；“自定义日期”功能目前仍在调试中。
  2. 填写当前库存资源，并根据实际情况启用日常收入、活动收入、常驻礼包、活动礼包以及钻石 / 红钻礼包。
  3. 页面中的“资源总计”会根据选择和输入实时更新，无需额外点击“计算”。

注意事项

本计算器目前仍处于开发和测试阶段，计算结果仅供参考，可能存在遗漏或计算错误，不代表游戏内最终实际情况。

如果发现计算结果异常，建议先检查当前日期、目标卡池、库存数量，以及各收入和礼包模块的启用状态。

建议与 Bug 反馈：小红书 @ZAP85

日期与计算范围

“当前日期”是本次计算的起点，“目标卡池”或“自定义日期”决定计算终点。

在“目标卡池”模式下：

  • 按开池日计算：只计入在卡池开启当天之前或当天即可获得的资源。
  • 按结束日计算：计入在卡池关闭前能够获得的全部资源。

绘旅人卡池实际结束时间通常为凌晨 5:00。为便于按日期计算，计算器会将结束日期记为实际结束时间的前一天。

例如：卡池实际时间为 2026.08.26 09:30 ～ 2026.09.03 05:00，计算器中显示为 2026.08.26 ～ 2026.09.02。

库存资源

“库存资源”用于填写当前已经持有的钻石、红钻和各种老荷兰颜料。

限时老荷兰请填写在当前目标日期仍然可以使用的数量。

限定老荷兰只适用于特定卡池。选择目标卡池后，计算器会自动匹配该卡池可使用的限定老荷兰。

日常收入与活动收入

月卡剩余天数直接按照游戏内显示的数值填写即可。计算器会根据当前月卡剩余天数和目标日期判断已有覆盖时间，并在需要时计算后续需要购买的月卡数量。

季旅专列、罐罐计划和猫条计划的购买选项会放在对应的活动礼包中。日常收入模块只计算这些项目每日或每月固定发放的资源，不显示购买金额，也不计入购买时立即获得的资源。

罐罐计划和猫条计划不会自动计算尚未提取的储存资源；如需将这部分资源计入结果，请在“个性化调整”中手动添加。

“活动收入”用于计算活动本身可以获得的免费资源。部分活动奖励会分阶段开放，因此目标日期不同，可计入的活动资源也可能不同。

未来活动的数据主要根据以往同类活动进行估算，仅供参考，不代表正式上线后的实际奖励。

常驻礼包与活动礼包

礼包中的“理论抽数”和“单抽价格”用于比较礼包所包含抽卡资源的理论价值。

部分活动礼包包含连续发放奖励。计算器默认在计算区间内礼包最早可购买的当天购买，并根据目标日期计算实际已经领取的奖励。

由于部分礼包中包含红钻，为便于统一估值和比较单抽价格，计算器提供“自定义红钻折算率”，默认折算率为1980 红钻 = 28 抽，可以根据实际情况自行调整。该折算率仅用于礼包理论价值计算，不代表红钻会在资源总计中自动兑换为抽数。

钻石 / 红钻礼包

“钻石 / 红钻礼包”使用游戏内钻石或红钻购买。

月卡用户可以使用“每周优惠十连”：1200 钻石 → 10 个老荷兰颜料

个性化调整

“个性化调整”用于处理计算器暂时没有单独建模的资源变化。

正数表示增加资源，负数表示减少资源。

例如：预计额外获得 300 钻石，可以填写 +300；预计额外消耗 500 钻石，可以填写 -500。

个性化调整会在其他收入和礼包结算完成后最后应用，因此最终资源允许显示为负数。

资源总计

“资源总计”显示当前所有已选择收入、礼包和手动调整后的最终资源结果。

钻石、普通老荷兰、限时老荷兰，以及当前目标卡池可使用的限定老荷兰，会共同用于计算“可用抽数”。

红钻默认不会自动兑换为钻石，也不会自动折算进可用抽数。

氪金总计与限时累充

“氪金总额”表示当前方案中选择购买的所有人民币项目总金额。

当计算区间内存在限时累充活动时，可以在“限时累充”中选择需要计算的限时累充活动。

常驻礼包默认可以安排在所选限时累充期间购买；活动礼包只有在其可购买时间与所选限时累充时间存在重合时才能计入。

月卡默认在计算区间内持续有效，因此计算器会根据月卡连续覆盖需求，加上额外购买月卡数量，自动计算本期可计入限时累充的最大数量；可根据实际情况自行更改“月卡计入本期”的实际数量。
